# نتائج المقارنة العملية: HeroUI وMantine

22 أكتوبر 2026 — React 19.3.1، TypeScript 7.0.2، Chrome 155 عبر Playwright. هذه المقارنة تنفيذ للتوصية في [تقييم المستودع](HEROUI-EVALUATION.md).

## النتيجة والاختيار

**أبقي Mantine أساس مكتبة أطلس الشاملة، وأتيح HeroUI بديلًا مستقلًا للتقييم البصري والتقويم الهجري.** نجحت المكتبتان في التدفقات الأربعة المحددة، ولم تكشف التجربة سببًا يستدعي تحويل جميع مكونات المكتبة الحالية. HeroUI يقدم مسار أم القرى الجاهز، بينما Mantine يظل متكاملًا مع امتدادات أطلس للرسوم والمحرر والملفات.

هذا استنتاج لاحتياجات أطلس؛ ليس ترتيبًا مطلقًا لجودة المكتبتين. الجمال تفضيل بصري يمكن فحصه الآن على المحتوى نفسه في [المقارنة المحلية](http://127.0.0.1:5173/compare/).

## معايير التجربة قبل الاختيار

| المعيار | طريقة التحقق |
|---|---|
| عدالة المحتوى | نفس أسماء الحقول والرسائل وقواعد التحقق والخمسة سجلات والتاريخ الابتدائي |
| المكونات الجاهزة | HeroUI وReact Aria مقابل Mantine وMantine DataTable؛ شيفرة التطبيق تدير الحالة والبيانات فقط |
| العربية والتدويل | RTL وLTR، تسميات عربية صريحة، معاينة ميلادية وأم القرى |
| الإتاحة والتفاعل | تحقق النموذج، Tab وEscape واستعادة التركيز، فرز وترقيم، اختيار يوم فعلي |
| الجوال | لمس فعلي محاكى في Chrome عند 390px، حدود قائمة الاختيار، واختيار التاريخ |
| الاتساق البصري | نفس عائلتي الخطوط، مظهر فاتح وداكن، مع الاحتفاظ بتكوين المكونات الأصلي وضبط التباين |
| حجم الإنتاج | جمع ملفات JS وCSS المستوردة لكل مدخل بعد gzip، وفق طريقة محفوظة قابلة للإعادة |
| عزل التكامل | مدخل HTML مستقل لكل مكتبة داخل iframe؛ لا يتسرب Tailwind أوHeroUI CSS إلى معرض Mantine |

| الجدول | فرز الاسم بالاتجاهين، وإعادة الصفحة عند الفرز، وترقيم 3 من 5 | النتيجة نفسها |
| التاريخ الميلادي | اختيار 23 أكتوبر يحفظ `2026-10-23` | النتيجة نفسها |
| أم القرى | عرض جمادى الأولى 1448؛ اختيار 12 منه يحفظ `2026-10-23` | المكوّن المثبت يبقى ميلاديًا، وتظهر رسالة توضح ذلك |
| اللمس عند 390px | اختيار قسم، إلغاء حوار، صفحة تالية، واختيار يوم | النتيجة نفسها |
| فحص axe الآلي | لا مخالفات مرصودة في الحالات الأربع بالمظهرين، مع الحوار والتقويم مفتوحين | النتيجة نفسها |

نتائج المشروع: **21 اختبار تكامل ناجحًا** تشمل اختبارات المعرض السابقة والمقارنة. تفاصيلها في `artifacts/test-results.json`؛ وفحص axe في مرفقات الاختبارات. لا تشمل هذه النتيجة كل مكونات المكتبتين أوقارئات الشاشة أوAndroid فعليًا، ولا تدحض بلاغ Drawer الذي لم يدخل نطاق التجربة.

## حجم ملفات التجربة

| المدخل | JavaScript gzip | CSS gzip |
|---|---:|---:|
| HeroUI 3.2.6 | 221.0 KiB | 40.5 KiB |
| Mantine 9.7.3 + DataTable | 175.6 KiB | 43.6 KiB |

المصدر الآلي: `artifacts/comparison-build-metrics.json`، وسكربت `scripts/prepare-comparison.mjs`. كل مدخل يجمع التدفقات الأربعة، والمجموع يشمل اعتمادياته الساكنة؛ ويستثني ملفات الخطوط وHTML وغلاف المقارنة وتكلفة الشبكة. يشمل جانب Mantine مكتبة DataTable المتخصصة. CSS كامل للمجموعة المستوردة، وليست مقارنة لمكوّن منفرد. **الحجم لا يقيس سرعة التشغيل أوالذاكرة أوإعادة الرسم**؛ وقد تختلف النتائج مع الانتقاء والتقسيم والتخزين المؤقت في تطبيق آخر.

## الخطوط والتخصيصات

- القرار المعتمد من المستخدم: **Free Palestine للعناوين، وNoto Sans Arabic للنصوص والحقول والأزرار**، مع خيار Noto للجميع.
- Free Palestine نسخة Regular 1.000 مثبتة على الجهاز. استُخدم `local()` فقط، دون نسخ ملف الخط إلى الحزمة. توثيق المصدر والحقوق والقياس في `research/free-palestine-font.json`.
- ضُبط حجم وجه Free Palestine المحلي إلى 185% لتقريب حجمه المرئي من سلم العناوين، مع وزن 400 وتعطيل الأوزان المصطنعة. الأجهزة التي لا تحتويه تستخدم Noto ثم خط النظام.
- ضُبط لون HeroUI الأساسي الفاتح إلى `#0067c0` والنص الثانوي إلى `#62626b`، وMantine إلى shade 9 في الفاتح، لتحقيق تباين النص الصغير. ليست النتيجة شهادة بأن ألوان الإعدادات الافتراضية متوافقة دون ضبط.
- أُعطيت أجزاء التاريخ التفاعلية في HeroUI مساحة لا تقل عن 24×28px عبر className الأصلية، مع تسميات عربية لأزرار الإغلاق والتنقل. استُخدم `weekdayStyle="narrow"` لتبقى أيام الأسبوع السبعة داخل نافذة التقويم بالعربية، وتحقق اختبار الجوال من حدود الخلايا. لا يوجد تنفيذ محلي لحقول أوأزرار أوحوارات أوتقاويم.
- ينتظر فحص التباين اكتمال حركة فتح الحوار؛ قياسه أثناء طبقة الانتقال يعطي ألوانًا عابرة غير ممثلة للحالة المستقرة.

## التشغيل وإعادة التحقق

```bash
npm run dev
# http://127.0.0.1:5173/compare/

npm run check
npm run provenance
npm run test:package
# مع تشغيل خادم التطوير:
node scripts/capture-comparison.mjs
```

بناء الإنتاج يضم المقارنة تحت `apps/catalog/dist/compare`؛ يمكن تشغيل `npm run preview -w @atlas/catalog -- --port 4173`. لا تحتاج استضافة منفصلة للمعاينتين في الإنتاج. HeroUI اعتماد لتطبيق المقارنة فقط، وليس اعتمادًا مباشرًا لحزمة `@atlas/ui` القابلة للتثبيت.
