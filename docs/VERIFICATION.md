## المقارنة والخطوط

- شملت المقارنة نموذجًا وحوارًا وجدولًا وتاريخًا بالمحتوى نفسه، مع فتح الحوارات والتقاويم في فحص axe بالمظهرين.
- اختُبر اللمس بمحاكاة Chrome بعرض 390px: قائمة الاختيار والحوار والترقيم واختيار التاريخ، مع التحقق من بقاء خلايا تقويم HeroUI داخل النافذة بعد اختصار أيام الأسبوع بخيار المكوّن. لا يمثل ذلك اختبار جهاز Android فعلي.
- تأكد الاختبار من تحميل Free Palestine المثبت محليًا للعناوين ومن بقاء body على Noto، وحفظ اختيار Noto بعد إعادة التحميل. لا يُوزع ملف Free Palestine.
- قياسات الإنتاج وحدودها في `docs/COMPARISON-RESULTS.md`؛ ولقطات المقارنة في `artifacts/comparison-form-*.png` والتقويم في `artifacts/*-calendar-*.png`.
- فحص الخطوط الميكانيكي محفوظ في `artifacts/typeset-scan.json`، دون ملاحظات.

## تحقق النشر على GitHub

- فحص GitHub Actions يثبت الاعتماديات وChrome على Ubuntu، ثم يفحص الأنواع والبناء والتكامل والتراخيص والحزمة في مشروع مستهلك جديد.
- جرى فصل `preview.proxy` عن تحويلات خادم التطوير؛ تخدم معاينة الإنتاج ملفات المقارنة المبنية مباشرة من خادم واحد.
- يتحقق اختبار المقارنة من غياب `/@vite/client` ووجود ملفات `compare-assets` في HTML الإنتاج، كي لا يخفي خادم تطوير يعمل بالخلفية نقصًا في النشر.

## إصلاحات تمت باستخدام API المصدر

- أُضيفت تسميات السحب إلى Slider عبر thumbLabel، وتسميات Progress.Section، وزر قطارة الألوان عبر eyeDropperButtonProps.
- أُعطي مثال الهيكل التحميلي دور group ملائمًا لتسميته.
- ضُبطت السمة لزيادة تباين النصوص الثانوية والـplaceholder بالمظهرين، مع احترام تقليل الحركة.
- تُخفى قائمة الهاتف المغلقة من التخطيط والتركيز عبر خاصية display المتجاوبة الأصلية.
- يستخدم Carousel اتجاه المزود الحالي، وتعرض شيفرة كل مثال الملف الفعلي الذي ينفّذه المعرض.
- استُكملت تراخيص Embla من وسم الإصدار، ورخصة react-remove-scroll-bar من نسخة مثبتة لمراجعة ملف الترخيص في المستودع؛ سجلات المصدر بجانبها في research. حُفظت تراخيص المصادر المضمّنة في victory-vendor أيضًا.

## حدود النتيجة

- النتائج تغطي المعرض والتكامل المحدد على Chrome، لا جميع متصفحات الويب والأجهزة أو جميع صادرات المكتبات الأصلية.
- فحص axe ليس شهادة توافق WCAG، ولم يُجرَ اختبار شامل بقارئات الشاشة أو مستخدمين فعليين. قياسات التباين الإضافية تغطي عينات محددة.
- آراء المستخدمين في التقرير من نقاشات عامة؛ لم تُجرَ مقابلات أو دراسة إحصائية.
- تواريخ معرض Mantine ميلادية بواجهة عربية. مقارنة HeroUI المنفصلة تعرض أم القرى مع حفظ ميلادي متحقق منه. لا توجد مصادقة أوخادم أورفع ملفات فعلي.
- حزمة .tgz تحتوي بوابات التصدير والأنواع والتراخيص؛ npm يثبت المكتبات الأصلية عند استهلاكها. تحتاج الإنترنت للتثبيت الأول، ويمكن استخدام cache بعد ذلك. لم تُنشر الحزمة أوالمعرض علنًا.
- CSS كامل نسبيًا في المعرض لأنه يعرض فئات كثيرة؛ التطبيق المستهلك يستورد CSS لكل امتداد يحتاجه. حجم المعرض لا يمثل حجم مكوّن منفرد.

## إعادة التحقق

```bash
npm ci
npm run check
npm run provenance
npm run test:package
```

لقياس التباين وحفظ لقطات فاتحة محدثة، شغّل `npm run dev` في نافذة أخرى ثم `node scripts/verify-contrast.mjs`. تشغيل الاختبارات يتطلب Chrome كما يوضح README.
