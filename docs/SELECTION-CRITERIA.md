# معايير الاختيار — تُعتمد قبل التثبيت

تاريخ وضع المعايير: 2026-10-22. النطاق الافتراضي: React + TypeScript، تطبيقات عربية RTL، ومكتبة من مكونات مفتوحة المصدر جاهزة؛ لا نطوّر بدائل محلية للمكونات.

## شروط الاستبعاد

1. ترخيص المصدر أو الحزمة غير واضح، أو المكوّن المطلوب مدفوع فقط.
2. غياب مصدر رسمي يمكن تتبعه أو غياب تكامل React موثق.
3. كسر التوافق بين حزم المجموعة أو الحاجة لنسخ قسري للاعتماديات.
4. عدم وجود طريق واضح لدعم اتجاه RTL أو تشغيل لوحة المفاتيح في المكونات التفاعلية الأساسية.
5. تكرار دور مكتبة مثبتة دون فائدة عملية واضحة.

الدرجات أحكام تحريرية قابلة للنقاش وليست قياسات مخبرية. لا توجد مكتبة «أفضل مطلقًا» لكل مشروع. الأوزان تفضّل مجموعة متماسكة وجاهزة على تجميع أنظمة متداخلة.

## الإضافات المتخصصة

تُقبل إضافة إذا عالجت فئة غير مغطاة جيدًا في الأساس، واجتازت شروط الاستبعاد، وظهرت في مثال يعمل. لا تُضاف مكتبات للزينة أو للشهرة وحدها. المكونات التجريبية و3D ومكتبات المؤثرات توثق كخيارات منفصلة بدل تحميلها على كل مشروع.

## مراجعات المستخدمين

تستخدم النقاشات العامة كإشارات نوعية عن سهولة التطوير والترقيات والتخصيص. لا تمثل إجماعًا أو إحصاءً، ولا نستخدم النجوم أو عدد التنزيلات كبديل لفحص الملاءمة.

## حدود التحقق

فحص الإتاحة آلي ويدوي محدود بمعرض الأمثلة. يجب على كل تطبيق يستهلك المكتبة فحص محتواه وتسمياته وتباينه وتدفقاته. التاريخ الهجري والتحرير الغني والسحب والإفلات تحتاج تقييمًا خاصًا إذا طلبت لاحقًا.
