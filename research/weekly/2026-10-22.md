## التحقق والقيود

نجح npm ci في Work السحابي. محاولة npm run check الأولية على main نجحت في الأنواع والبناء، لكن اختبارات المتصفح لم تبدأ فعليًا بسبب غياب Chrome في Work؛ لا تعد هذه إخفاقات مثبتة للمكونات. يُنفذ التحقق النهائي للتعديل داخل GitHub Actions الذي يثبت Chrome، ويجب مطابقة commit الفرع ومرجع دمج PR الاختباري وفحص نجاح npm ci وcheck وprovenance وtest:package قبل اعتبار الطلب جاهزًا. تتضمن الاختبارات الحالية العربية والاتجاهين والمظهرين والجوال وaxe وسلوك النماذج والحوارات والخط البديل؛ ليست اختبارًا يدويًا شاملًا لكل تقنية مساعدة.

تُسجل نتيجة CI النهائية وروابط PR والتشغيل في وصف طلب السحب المرتبط بهذا التقرير، لتظل منسوبة إلى commit التقرير نفسه دون إضافة commit لاحق يغير مرجع التحقق. لا دمج main أو نشر npm أو تغيير للجدولة المحلية.
